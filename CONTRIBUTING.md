# Contributing

Keep each change tied to a concrete report-writing or packaging problem. The skills are intentionally Vietnamese-first; English documentation should make installation and scope clear without pretending the skill bodies have been translated.

1. Describe the task, failure, and expected behavior without sharing private report content.
2. Update the smallest relevant skill or routing rule. Keep domain-specific preferences outside the general workflow.
3. Update links, examples, and metadata affected by the change.
4. Install the development dependency and run the checks described in README.md.
5. For behavioral changes, try the relevant cases in EXAMPLES.md and report what was actually observed. Static checks do not measure writing quality.
6. For formatting guidance, verify a representative document in the stated target application before claiming a rendering fix.

The root plugin manifest and Claude plugin manifest share a name, version, and license. The two marketplace catalogs expose that same plugin. Skill names must remain unique and match their directory names.

Do not add copied third-party instructions without checking attribution and license requirements. New contributions are provided under this repository's MIT license.
